# VS Project Starter

A Visual Studio project starter includes: a `README.md`, a build script, a test script, a `.gitignore`, a `LICENSE`, a `CHANGELOG.md`. For Rust: `cargo new --lib` + `cargo new --bin` + a workspace. For Node: `npm init -y` + a `src/`, `test/`, `dist/` structure. Always start with tests, not with code.
