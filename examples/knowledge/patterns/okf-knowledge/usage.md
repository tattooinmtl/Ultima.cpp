# OKF

OKF (Open Knowledge Format) is a directory of Markdown cards with frontmatter. Each card has `id`, `title`, `type`, `tags`, `links`. Sub-folders under `knowledge/<category>/<sub>/` group related cards. The harness seeds the library on first run; add cards by dropping `.md` files in the right folder.
