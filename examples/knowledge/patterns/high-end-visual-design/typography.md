# High-End Visual

Typography: one serif display + one sans body, or all one family with extreme weight contrast. Spacing: a strict scale (4, 8, 12, 16, 24, 32, 48, 64). Shadows: subtle, layered, never colored. Color: one signature accent, rest neutrals. Cinematic composition: a single dominant element per screen.
