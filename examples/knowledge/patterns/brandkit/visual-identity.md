# Brandkit

A brand has 5 things: a logo concept (geometric, not a wordmark), 2-3 brand colors (one signature, one neutral, one support), a type system (one display + one body), an iconographic system (geometric primitives, not illustrations), and a voice (3-5 words: e.g. "precise, warm, technical"). Everything else flows from these.
