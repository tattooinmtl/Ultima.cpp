# Find Skills

Skills are OKF cards under `~/.agnes/knowledge/<category>/<sub>/`. Search with `find_skills("rust error handling")` or browse the `/skills` slash command. Each card has tags; filter by tag to narrow. To learn a new domain, scan the category for the top-level structure first.
