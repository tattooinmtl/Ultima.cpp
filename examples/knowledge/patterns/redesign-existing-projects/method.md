# Redesign

1. Audit the current state — screenshots, user paths, what's broken. 2. Identify the worst 3 offenders (most generic AI patterns, biggest a11y misses). 3. Define a single design direction (1 page, 1 paragraph). 4. Ship the redesign of those 3 first. 5. Apply the new standard incrementally. 6. Don't break existing functionality.
