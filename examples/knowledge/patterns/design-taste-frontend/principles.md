# Design Taste

Pick a real type system + real type scale. Use real grid (12-col or 8-pt). Choose a deliberate palette — one accent, one neutral, one highlight. Whitespace is content. Avoid generic SaaS look (no purple-gradient, no card-with-shadow on every surface). Audit before/after with a real screenshot, not vibes.
