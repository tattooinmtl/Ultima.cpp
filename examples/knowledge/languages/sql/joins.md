# Joins

`INNER JOIN` for matches-only. `LEFT JOIN` for all-left + matching right (NULL when no match). `FULL OUTER JOIN` for all-of-both. `CROSS JOIN` is the cartesian product. `LATERAL` (Postgres) runs a subquery for each row of the outer query.
