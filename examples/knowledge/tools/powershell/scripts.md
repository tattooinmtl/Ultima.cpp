# PowerShell

`Get-ChildItem` not `ls`. `Select-Object` not `grep`. Pipeline objects, not strings. `$ErrorActionPreference = 'Stop'` at the top for fail-fast scripts. `Get-Help Cmd-Name -Examples` to learn. Use `pwsh` (PowerShell 7+) on Windows + Linux.
