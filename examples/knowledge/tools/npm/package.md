# package.json

`name`, `version`, `type` (`module` for ESM), `scripts`, `dependencies`, `devDependencies`. Pin major versions: `"react": "^18.2.0"`. Use `engines.node` to require a Node version. Use `"exports"` to define subpath entry points.
